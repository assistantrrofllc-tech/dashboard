# Changelog

## [1.0.0] - 2026-02-15

### Added
- **Calendar**: Monthly view with prev/next navigation, click-to-add events, color-coded categories (work, personal, TechQuest, health)
- **Task Management**: Add/complete/delete tasks with categories, priority levels (high/medium/low), due dates, filtering
- **Reminders**: Overview section showing upcoming events and tasks due within 7 days, urgent highlighting
- **Finance Tracker**: Income/expense log, monthly totals, spending by category bar chart, transaction table
- **CEF Portfolio**: Display holdings with shares, current price, gain %, dividend yield, total portfolio value
- **Design**: Dark theme with glassmorphism, cyan/green accents matching TechQuest aesthetic, animated background
- **Mobile Responsive**: Optimized for Samsung Galaxy S22 and all screen sizes
- **Data Persistence**: LocalStorage + JSON sample data files in /data/ subfolder
- **Sample Data**: Pre-loaded events, tasks, and financial transactions for demo
- **Modals**: Add event, task, and transaction modals with form validation
- **FAB Button**: Context-aware floating action button for quick additions
