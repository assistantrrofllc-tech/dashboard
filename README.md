# Rob's Personal Dashboard

Phase 1 of a 3-phase product: Personal Dashboard → RROF Project Management → TechQuest Product.

## Features
- 📅 Calendar with monthly navigation and color-coded events
- ✅ Task management with categories, priorities, and due dates
- 🔔 Reminders for upcoming events and deadlines
- 💰 Finance tracker with income/expense logging and spending charts
- 📈 CEF portfolio overview with yields and gains

## Tech Stack
- Pure HTML/CSS/JS — no frameworks, no build step
- LocalStorage for persistence
- JSON files in `/data/` for Kai to read/write programmatically
- Deployable on GitHub Pages

## Data Files
- `data/events.json` — Calendar events
- `data/tasks.json` — Tasks
- `data/finance.json` — Transactions + CEF portfolio
